# Lumina UI

Библиотека для красивых, быстрых и гибких интерфейсов в Minecraft.

- Minecraft 1.20.1 (Forge) и 1.21.1 (NeoForge)
- Ядро на чистой Java без Minecraft: flex-раскладка, стили с темами и состояниями, плавные анимации и пружины, события, реактивные сигналы
- SDF-рендер: скругления, обводки, мягкие тени, градиенты

Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Сборка

Нужен JDK 21 (для Forge 1.20.1 Gradle сам скачает JDK 17 через toolchains).

```
gradlew :core:test :testmod-common:test      # тесты ядра и прогон витрины, без Minecraft
gradlew :forge-1.20.1:runTestmodClient       # игра с библиотекой и тестовым модом (Forge 1.20.1)
gradlew :neoforge-1.21.1:runTestmodClient    # то же для NeoForge 1.21.1
gradlew :forge-1.20.1:runClient              # только библиотека
gradlew build                                # jar библиотеки в */build/libs
```

## Тестовый мод (витрина)

Отдельный мод `luminatest`, который использует библиотеку как обычный сторонний мод.
Общий код витрины — `testmod-common/` (только API ядра), загрузочная часть — `*/src/testmod/`.

Открыть витрину: клавиша **K** в мире, команда `/luminatest` или кнопка **Lumina** в главном меню и меню паузы.

Разделы: обзор, раскладка (justify, grow, align, слои, вложенность), стили и темы (скругления, тени,
градиенты, состояния, смена темы и акцента на лету), анимации (функции плавности, пружины, переходы стиля,
бесконечная анимация), ввод и события (перетаскивание, фокус и клавиатура, журнал захвата и всплытия),
данные (сигналы, вычисляемые значения, динамический список), производительность (время кадра,
анимированная сетка из 240 фигур, список из 1000 строк).

Библиотека сама по себе тоже содержит маленькое демо: `/lumina demo`.
