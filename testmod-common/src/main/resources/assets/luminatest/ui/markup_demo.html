Lumina Market

Разметка превращается в обычные виджеты при загрузке, поэтому в кадре она ничего не стоит. Стили — это CSS с селекторами, состояниями :hover, переменными и @keyframes.

Логика: {{имя}} в тексте, bind у полей, on-click у кнопок, if для показа. Без Java: <state> и действия inc dec set toggle sound.

Файлы лежат в assets/luminatest/ui/ — переопределите их ресурспаком и нажмите F3+T.
