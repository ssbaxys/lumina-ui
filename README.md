# Lumina UI

Библиотека для красивых, быстрых и гибких интерфейсов в Minecraft.

- Minecraft 1.20.1 (Forge) и 1.21.1 (NeoForge)
- Ядро на чистой Java без Minecraft: flex-раскладка, стили с темами и состояниями, плавные анимации и пружины, события, реактивные сигналы
- SDF-рендер: скругления, обводки, мягкие тени, свечение, градиенты (линейные, радиальные, конические, до 8 цветов), режимы смешивания
- Цвета RGB/HSV/HSL/OKLCH, токены темы (акцент, скругление, скорость анимаций меняются на лету), несколько классов стиля
- Анимации: ключевые кадры, последовательности, циклы, yoyo, 23 кривые и пружины
- Ванильные эффекты в интерфейсе: огонь, взрывы, падающий TNT, лава, дым, тряска
- Виджет Markdown (таблицы, списки, задачи, ссылки, иконки предметов), выбор цвета, круговой прогресс

Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Оформление, анимации, эффекты и Markdown: [docs/STYLING.md](docs/STYLING.md). Интерфейс на HTML и CSS с логикой: [docs/MARKUP.md](docs/MARKUP.md).

## Сборка

Нужен JDK 21 (для Forge 1.20.1 Gradle сам скачает JDK 17 через toolchains).

```
gradlew :core:test :testmod-common:test      # тесты ядра и прогон витрины, без Minecraft
gradlew :forge-1.20.1:runTestmodClient       # игра с библиотекой и тестовым модом (Forge 1.20.1)
gradlew :neoforge-1.21.1:runTestmodClient    # то же для NeoForge 1.21.1
gradlew :forge-1.20.1:runClient              # только библиотека
gradlew build                                # jar библиотеки в */build/libs
```

## Тестовый мод (витрина)

Отдельный мод `luminatest`, который использует библиотеку как обычный сторонний мод.
Общий код витрины — `testmod-common/` (только API ядра), загрузочная часть — `*/src/testmod/`.

Открыть витрину: клавиша **K** в мире, команда `/luminatest` или кнопка **Lumina** в главном меню и меню паузы.

Разделы: обзор, современный стиль (экран настроек: боковое меню, вкладки, карточки, ползунки с полями, цвета), раскладка (justify, grow, align, слои, вложенность), стили и темы (скругления, тени,
состояния, токены, несколько классов, переходы по свойствам), цвета (выбор цвета, RGB/HSV, операции,
пространства смешивания), градиенты (все виды, пресеты, анимированные рамки, режимы смешивания),
анимации (галерея кривых, ключевые кадры, последовательности, пружины), эффекты (огонь, взрывы,
падающий TNT, лава, спрайты, предметы), Markdown, HTML и CSS, блоки, 3D-постройки, поля ввода, кнопки и флажки, компоненты (таблицы, деревья, графики, текст с эффектами), окна и живые обои, ввод и события (перетаскивание, фокус и клавиатура, журнал захвата и всплытия),
данные (сигналы, вычисляемые значения, динамический список), производительность (время кадра,
анимированная сетка из 240 фигур, список из 1000 строк).

Библиотека сама по себе тоже содержит маленькое демо: `/lumina demo`.
