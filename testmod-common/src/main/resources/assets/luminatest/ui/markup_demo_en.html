Lumina Market

Markup turns into ordinary widgets on load, so it costs nothing per frame. Styles are CSS with selectors, :hover states, variables and @keyframes.

Logic: {{name}} in text, bind on fields, on-click on buttons, if for visibility. Without Java: <state> and the actions inc dec set toggle sound.

The files live in assets/luminatest/ui/ — override them with a resource pack and press F3+T.
